# Reactive Cartel
This mod changes the cartel's activity to be more prominent as you progress through the in game ranks! As you level up, the Benzies will start getting more aggressive with their tagging, dealer robberies, and ambushes! Additionally, as you level up, the Benzies will get more violent too!

## Features
Benzies will get more active and aggressive as you progress through the game!

## Compatability
- Only compatible on the Main branch of the game.
- Compatability with mods such as CartelEnforcer is unlikely, but not tested. Test at your own risk!

## Installation
1. Install [MelonLoader](https://melonwiki.xyz/).
2. Download the .zip file.
3. Drag the "ReactiveCartel.dll" file into your mods folder.
4. Download and install S1API from the dependencies list.
